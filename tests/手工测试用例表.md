## 附：接口自动化测试

除手工用例外，`tests/api-test.js` 提供接口层自动化回归：

```bash
node tests/api-test.js           # 本地后端，21 项全跑（含交易全流程）
node tests/api-test.js online    # 线上后端，只读+鉴权 12 项（自动跳过写入用例）
```

覆盖：鉴权（登录/错误密码/token 校验）、大厅分页与筛选、用户钱包账单、会话消息、
交易全流程（发布→下单→接受→双方确认→评价）及错误分支（自己帖下单、重复评价）。
